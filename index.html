スクロール視聴実験

縦にスクロールして次の動画を見る画面です。後ろにいくほど、お題と関係のない動画の割合が増えます。

このファイルを直接開いているため、YouTubeの動画は再生されません（エラー153）。Webに置くか、パソコンで簡単なサーバーを起動して、http:// のアドレスで開いてください。

この設定での並び（左が1本目）

お題に関係ある関係ない
本物の動画に差し替えるには

ファイル先頭付近の REAL に、動画のIDを並べます。今は、関係ある5本と関係ない6本が入っています。本番は、各40本ほど必要です。TikTokは、URLの /video/ のあとの数字がIDです。このファイルは、Webに置いたときだけ動画が再生されます。

const REAL = {
  related:   [{type:'youtube', id:'動画ID'},
              {type:'tiktok', id:'投稿ID（数字）'},
              {type:'file', src:'videos/r01.mp4'}],
  unrelated: [{type:'youtube', id:'動画ID'}]
};

視聴を終了しました

この視聴の要約

最後の1本（時間切れや終了ボタンで途中になった動画）は、すぐスキップの割合・最後まで見た割合・滞在時間の中央値には入れていません。
