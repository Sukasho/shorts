スクロール視聴実験

縦にスクロールして次の動画を見る画面です。後ろにいくほど、お題と関係のない動画の割合が増えます。

このファイルを直接開いているため、YouTubeの動画は再生されません（エラー153）。Webに置くか、パソコンで簡単なサーバーを起動して、http:// のアドレスで開いてください。

この設定での並び（左が1本目）

お題に関係ある関係ない
本物の動画に差し替えるには

ファイル先頭付近の REAL に、動画のIDを並べます。今は、関係ある5本と関係ない6本が入っています。本番は、各30本ほど必要です。このファイルは、Webに置いたときだけ動画が再生されます。

const REAL = {
  related:   [{type:'file', src:'videos/r01.mp4'},
              {type:'youtube', id:'動画ID'}],
  unrelated: [{type:'file', src:'videos/u01.mp4'}]
};

視聴を終了しました
